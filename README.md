# MediGuard AI – Healthcare Virtual Assistant

MediGuard AI is a web-based healthcare assistant demo that provides basic symptom-related information through an interactive chatbot.

## Features
- Interactive healthcare chatbot
- Keyword-based symptom responses
- Basic emergency keyword alerts
- Python Flask backend integration
- Responsive web interface
- Clear chat functionality

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Python
- Flask
- Flask-CORS

## Project Structure
- `index.html` – Webpage structure
- `style.css` – Website design
- `script.js` – Chat interface and API integration
- `app.py` – Python Flask backend
- `requirements.txt` – Python dependencies

## How to Run

1. Install Python.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the backend:

   `python app.py`

4. Open `index.html` in your browser.

## Disclaimer
This is an educational project demo. It does not provide medical diagnosis or replace professional medical advice. It should not be used for emergency decisions.
