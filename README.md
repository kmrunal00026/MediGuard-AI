# MediGuard AI – Healthcare Virtual Assistant

MediGuard AI is a simple web-based healthcare assistant demo designed to provide basic health information through a chat interface.

## Features
- Interactive chatbot interface
- Basic keyword-based symptom responses
- Emergency keyword alert
- Clear chat functionality
- Enter key support
- Message timestamps
- Responsive design
- Smooth animations

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html – Webpage structure
- style.css – Styling and responsive design
- script.js – Chatbot functionality

## Disclaimer
This is an educational project demo. It does not provide medical diagnosis or replace professional medical advice.
